SHOREBREAK / VỰC LẶNG — concrete budgets and limitations

Rendering strategy
Static Three.js r170, WebGL 2, self-hosted assets. No runtime CDN or npm/build.
One tier-bounded torch shadow map; no bloom, SSAO or full-screen postprocessing.
One rendered view plus the cached shadow pass described in DIVE-TOOLS.txt.
World materials use shared analytical caustics. Camera remains first person.

Quality tiers: low / medium / high
Pixel ratio cap:               0.8 / 1.2 / 1.6
Particle draw range:            450 / 850 / 1350
Fish instances per school:     12 / 25 / 42 (5 schools, culled by distance)
Repeated habitat density:      46% / 75% / 100%
Habitat detail radius:         90 / 123 / 170m (tile centers)
Terrain tile radius:           144 / 184 / 229m (tile centers)
Light shafts:                  off / 5 / 5
Torch distance:                30 / 38 / 46m
Torch shadow map:              256 / 512 / 768px
Torch maximum shadow updates:  12 / 20 / 30Hz (stationary map reused)
Large creature quality:        LOD / LOD / distance LOD+full

Original seeded/fallback world: 48 terrain tiles, 55,296 terrain triangles in entire fixed world;
612 rock instances, 707 branching corals, 1,316 kelp, 266 sea fans, 855 sponge
tubes, 388 cylindrical rock/landmark colliders. Habitat is generated once,
then its draw counts and visibility are changed in place. Frustum culling
also applies to world meshes. Small fish use shared geometry and material.
Max 3 large creatures; only loaded visible creatures update skeleton poses.
GLBs load in proximity to habitat; full variant loads only near on high tier.
Loaded variants remain cached, not unloaded during one session. High/LOD
switches share an absolute animation time to avoid a phase reset. The later
Blender vegetation replacement uses its separate capped populations below.

Simulation/UI
90Hz fixed step, capped catch-up; all simulation and animation stop on pause.
Input has keyboard/pointer ownership and clear-on-blur/cancel. HUD text is
updated at 10Hz; projected navigation markers move each visual frame.
Banked progress saves only when serialized banked/deepest data changes.
Auto quality starts medium/low and drops after 5 seconds of >32ms frame time.
The performance label is a local rolling render-loop estimate, not a promise.

Not implemented / not verified
No streaming terrain downloads, GPU occlusion queries, compressed KTX2 textures,
Draco decode or custom meshopt pipeline. GLBs are embedded-image files and
fetch only when useful; model counts are recorded in ASSET-MANIFEST.json.
Actual Mac browser QA now runs WebGL2 on Apple M2 / Chrome 154. Seven-second
requestAnimationFrame samples near the Warden averaged 55.44 FPS High,
57.01 Medium and 57.86 Low. End-of-sample draw calls / triangles were
74 / 153,952; 68 / 95,290; 51 / 55,628 respectively. These are short frame
cadence samples, not GPU timer queries or a whole-map benchmark. An earlier
moving reef sample averaged about 48 FPS; there is no steady-60 guarantee.
No physical-phone/touch, successful pointer-lock acceptance, native held-key
or audio-output QA was performed. Cloud Chromium remains blocked by local
IPC restrictions; its Node application tests still use renderer stand-ins.
See MAC-QA.md for the actual-device method and exact limitations.

First-person arm addition (new local feature)
One additional skinned draw primitive: 16,794 triangles, 37 joints, one
embedded 512px roughness texture, 981,224-byte GLB. Four preallocated mixer
actions; no second render pass, overlay scene, shadow map or new world light.
Camera-space collision probes run at approximately 10Hz. Actual resolved
physics displacement feeds stroke strength; blocked movement settles to idle.
The earlier M2 frame-cadence figures predate these arms. They must not be
represented as performance measurements of the new arm build.

New underwater optics candidate

Articulated motion candidate
No new GLBs or textures; species overlays reuse real weighted bones and cached
track interpolants. Large creature kinematics step at 90 Hz; only visible LOD
meshes are posed. Small fish share one 137-triangle deforming geometry, up to
210 instances. Four jellyfish add at most 8 transparent draws and 12,672 triangles
with low-tier reductions and reusable CPU buffers. The pre-art motion milestone passed178 tests on cloud and Mac, with partial
actual articulated-pose acceptance in MOTION-MAC-QA.md. New-motion GPU timings
remain unmeasured.

variants, global320/220/140 visible-instance caps and96/64/0 full-detail caps

geometry; per-frame allocations and transparent leaf sorting are avoided.

Actual integrated-art performance remains unverified; the later Mac browser

DYNAMIC SEA / V8
The four-minute deterministic weather cycle keeps the existing8,192-triangle
water and960-triangle sky: no extra draw pass, reflection target, texture or
particle allocation. Three swell bands and3/4/5 normal octaves remain capped.
Weather uniforms update in place; bounded whitecaps reuse the surface shader.
No new player forces; deep effects decay, shore/buoy displacement is damped.
These are implementation budgets, not measured GPU/frame-rate results.
